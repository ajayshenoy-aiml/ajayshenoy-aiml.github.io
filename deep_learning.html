Introduction to Deep Learning and PyTorch

A structured, hands-on, PyTorch-powered curriculum covering the fundamentals of neural networks, training, regularisation, and convolutional architectures.

Basic Python is all you need.

Prior ML knowledge is NOT required.

Prior PyTorch knowledge is NOT required.

Four modules, each with a capstone project. You will implement everything - autograd, training loops, data pipelines, CNNs - directly in PyTorch, without abstractions that obscure what is actually happening.

Modules

01

PyTorch Fundamentals

Build intuition for tensors, autograd, and the training loop from scratch. You'll fit a line manually with no nn.Module, then use nn.Sequential, save and load weights, and finish by learning a polynomial's coefficients from noisy data.

Tensors & dtypes Autograd Manual training loop nn.Sequential Save & load Capstone: polynomial fitter
02

Classification & Regression

Apply the training loop to real tabular datasets across three problem types. You'll train binary classifiers, multiclass classifiers, and regression models - and develop a precise understanding of when to use each loss function.

Binary classification Multiclass classification Regression BCELoss / CrossEntropyLoss / MSELoss Tabular datasets Capstone: end-to-end binary classifier
03

Reliability

Move from a model that runs to one that trains reliably. You'll build proper data pipelines, compare activation functions, add dropout, schedule the learning rate, checkpoint training, and implement early stopping.

Custom nn.Module Dataset & DataLoader Activations Dropout LR scheduling Checkpointing Early stopping Capstone: end-to-end multiclass classifier
04

Convolutional Neural Networks

Extend from tabular data to images. You'll visualise filter effects and pooling on real colour images, train an MLP baseline, build a CNN from scratch, implement LeNet-5, then beat all baselines with a custom CNN using BatchNorm and dropout.

Conv2d & padding MaxPool & AvgPool RGB image classification MLP baseline LeNet-5 BatchNorm2d Capstone: image CNN

What you'll learn

✓ How PyTorch tensors work - shapes, dtypes, slicing, matmul, and broadcasting
✓ How autograd builds a computation graph and why .backward() works
✓ How to write a complete PyTorch training loop without any high-level wrapper
✓ When to use BCELoss vs CrossEntropyLoss vs MSELoss - and why it matters
✓ How to build a proper data pipeline with Dataset and DataLoader
✓ Why dropout and LR scheduling improve generalisation, and how to tune them
✓ How convolutional filters, pooling, and BatchNorm work together in an image classifier
✓ How to checkpoint training and resume from any saved epoch
