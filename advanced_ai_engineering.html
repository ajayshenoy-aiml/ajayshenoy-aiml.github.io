Go from "I build LLM apps" to architecting and optimizing them for a hundred thousand concurrent users.

Saturday track — the core course everyone takes

The general, heavily practical course. Each month builds on the last: by the end you've optimized every layer — the model, the kernels, the engine, the cluster, the cloud.

Ship a real multimodal RAG on stock code, deploy it, and load-test it until it breaks — then learn the GPU and transformer fundamentals that explain every number in your benchmark.

An optional Sunday stream for candidates who want to go a level deeper than the general material — from writing hardware code by hand to building your own inference engine and finetuning your own models. Every student receives the full book and all code files regardless of track; Sunday is for those who want to build it all themselves.

Llama architecture Pure PyTorch
